## 1. Ringkasan Proyek

Portofolio pribadi berbentuk website statis sebagai **tugas akhir sumatif (UAS)** mata kuliah Kewarganegaraan. Website memperkenalkan diri sebagai mahasiswa Informatika dan warga negara Indonesia yang bersemangat di bidang *frontend development*, serta menghubungkan seluruh rekam jejak tugas WordPress selama tiga semester.

### Teknologi
- **HTML5, CSS3, dan Vanilla JavaScript (murni)**
- Gaya desain: modern dengan *dark tech aesthetic* (terinspirasi template Soumyajit)
- Ringan, cepat, dan bisa langsung dibuka di browser tanpa Node.js / npm

### Struktur Navigasi
| Section | Isi |
|---|---|
| `#home` | Hero section dan perkenalan singkat |
| `#about` | Profil, pendidikan, keahlian desain |
| `#projects` | Skill & teknologi, daftar proyek, jobdesc pribadi, rekam jejak WordPress |
| `#experience` | Pengalaman mengikuti event (Bootcamp Genesis 1.0 dan Indocomtech 2025) beserta foto |

> Halaman Resume ditiadakan. **Refleksi tidak dibuat di website** karena semuanya sudah ada di WordPress (lihat bagian 5).

## 6. Rencana Teknis (Tahap 2)

### Struktur Folder
```
portofolio/
├── index.html
├── style.css
├── script.js
└── assets/
    ├── img/          (foto Bootcamp Genesis 1.0 dan Indocomtech 2025)
    └── icons/
```

### Panduan Desain
- **Tema:** dark tech, latar gelap dengan satu warna aksen (contoh biru/ungu neon)
- **Font:** satu font sans-serif modern untuk teks, satu font monospace untuk aksen kode
- **Komponen:** navbar tetap (sticky), hero, kartu proyek, kartu timeline WordPress, footer
- **Animasi:** fade-in saat scroll (IntersectionObserver), hover halus pada kartu dan tombol
- **Responsif:** nyaman di HP, tablet, dan desktop
- **Navigasi:** smooth scroll ke `#home`, `#about`, `#projects`
